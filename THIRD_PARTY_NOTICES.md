## React Bits

`components/react-bits/fade-content.tsx` adapts the FadeContent pattern from [React Bits](https://github.com/DavidHDev/react-bits), Copyright (c) 2026 David Haz. It replaces the animation engine with the browser Web Animations API, uses a single entrance transition, and honors reduced motion. No React Bits package or GSAP dependency is installed.
