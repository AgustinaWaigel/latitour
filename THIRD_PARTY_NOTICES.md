## React Bits

The `components/react-bits/fade-content.tsx` component is a lightweight adaptation of the FadeContent pattern from [React Bits](https://github.com/DavidHDev/react-bits), by David Haz. It replaces its animation engine with the browser Web Animations API, uses a single entrance transition, and honors reduced motion. No React Bits package or GSAP dependency is installed.
